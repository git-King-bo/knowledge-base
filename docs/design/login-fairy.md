全部可见文字、品牌图标、输入框、密码显隐、登录按钮、暂停与跳过仍使用 HTML/SVG/CSS。图片不是界面截图；真实表单继续使用原认证 API。默认用户名改为空，显示与参考一致的占位文案。

## 等比与动效修正

针对宽屏截图中的横向拉伸，删除 `object-fit: fill` 和宽高独立拉伸。当前使用固定 `1586 / 992` 的场景容器，按屏幕宽、高中较小的可用等比尺寸布局；移动端使用同一比例。精灵为原有透明 `knowledge-fairy.webp` 的独立图层，图片高度自动计算、保持 `616 / 640` 比例。

内置 Image Gen 从纯美术场景中移除精灵，保留星云、纸页和原有光轨，生成 `frontend/public/mascot/fairy-celestial-background.png`。精灵使用原始角色素材，保持身份与透明边缘；背景没有被拉伸用来补满屏幕。

动效恢复为独立的轮廓显光、原画渐显、上下悬浮、金蓝光轨流动、星尘升起、魔杖呼吸和成功施法。所有 CSS 动效均响应暂停与减少动态效果。登录成功淡出和跳过逻辑不变。

实测 390×844、1586×992、1920×958 三种视口，角色 CSS 宽高比均约为 0.9625，与原始 616/640 一致；无横向溢出。通过间隔采样确认精灵 transform 和星轨 stroke-dashoffset 均持续变化，暂停后均停止且运行中动画为零；完整模拟登录成功进入工作空间并解除交互锁，控制台无应用错误。类型检查、正式构建与 46 个前端测试通过。

## 开场与星空活性更新

保持紧凑字号和尺寸上限，桌面插画整体向左 40px、表单向右 60px，增加两者之间的留白；1320px 以下回到窄屏布局。

开场改为 3.6 秒分段编排：星轨聚光 → 轮廓勾勒 → 材质自上而下显现 → 轻微姿态回正 → 悬浮待机。表单全程可操作；右上角「重播开场」仅重新挂载美术组件，不清空输入或重新请求认证。

星空增加 22 秒缓慢漂移、两层独立云光、44 个独立闪烁星点和错开周期的流星。背景、角色、光轨分层运动，所有动画遵循暂停与系统减少动态效果。

浏览器分时检查了 800/1800/3800ms 开场：材质透明度分别约 0/0.715/1，轮廓分别约 1/1/0。实时采样确认星云 transform、云光透明度、星点透明度和星轨 stroke-dashoffset 均变化；暂停后运行中的动画为 0；重播保留用户名。390×844、1280×800、1920×958 无横向溢出。完整模拟登录转场成功，控制台无应用错误。类型检查、正式构建与 46 个前端测试通过。

## 随机星闪、柔光显形与隧道统一

原画中主要亮星增加对齐的辉光闪烁，64 个局部星点使用随机位置、周期及错峰；Canvas 的 110 个星点在每一轮选择新的亮度，避免整齐重复的呼吸。人物加载改为羽化遮罩显形、棱光扫描、召唤光环和粒子，替换硬边裁切。

隧道 Canvas 使用透明上下文，起步不铺不透明底；`FairyAwakening.portalOrigin()` 提供原画星轨的实际中心及比例，登录前后测量并传给隧道。椭圆光轨从同一中心起步，精灵先化光淡出，隧道再渐入深色背景、向屏幕中心移动并加速穿行。2300ms 开始整体淡出，3200ms 完成。手机上保持原插画的垂直位置，避免切入固定层时跳动。

浏览器确认：桌面隧道起点与插画中心逐坐标一致；成功后约 307ms 人物仍完整可见、材质无遮罩，不被不透明底提前覆盖；后续可见完整透视隧道，成功进入工作空间并解除 inert，控制台无应用错误。随机星点周期各异且亮星透明度随时间变化。减少动态模式 0 个运行动画、人物完整可见、手机无横向溢出。现有成功登录测试新增共用星轨中心的集成断言，46 个测试通过；类型检查和正式构建通过。

## 收尾顿挫修正

修复前浏览器逐帧采样发现：计时器移除覆盖层时，最后可见帧仍约有 6.2% 不透明度；CSS 950ms 淡出与 900ms 后强制卸载不一致，且低帧率下隧道累计的截断 dt 会落后于墙钟收尾。

改为由覆盖层自身的 opacity transitionend 完成切换；忽略子元素和其他属性的结束事件；缺少事件时在完整淡出之后再用超时兜底，避免锁住页面。淡出为 900ms 线性合成，覆盖层仅在入场时声明 will-change。隧道按实际经过时间推进，高分屏 Canvas 约束在 200 万像素，减少收尾合成开销。

浏览器在 1920×958、DPR 2 下复测，结束事件透明度为 0，切层后工作空间可交互且无应用错误；该次收尾 450ms 内最大帧间隔约 34.2ms（该浏览器采样约 30fps，不代表所有设备帧率）。回归测试覆盖透明度完成、子元素事件过滤、事件丢失兜底和只完成一次；47 个前端测试、类型检查与正式构建通过。

## 人物显形结束的连续性与蓝色星云亮星

本次修复的是人物显形完成后的顿挫，而非登录隧道结束：原悬浮动画延迟 3.6 秒启动，延迟前 transform 为 none，启动帧立即旋转 -0.4 度。改为从开场起运行连续悬浮，起点旋转为 0；入场姿态在内层叠加并平滑回到中性位置。轮廓与棱光结束时间稍作错开，避免在同一帧同时结束。

从背景原图亮像素读取星点坐标，新增 58 个对齐原画的闪烁点，其中 46 个位于用户指出的下部蓝色星云区域。星点随星云层移动，使用随机周期和相位，局部亮起后淡下，保留暂停与减少动态效果。

逐帧检查 3580/3590/3600/3610/3620ms 的组合变换：每 10ms 位移变化最多约 0.0433px，旋转矩阵项变化最多约 0.000057，没有延迟结束时的突跳。蓝色星云中 46 个点在 1.1 秒采样内有 14 个亮度明显改变。新页面验证暂停后 0 个动画运行，手机无横向溢出；完整模拟登录与工作空间解锁通过，无应用错误。类型检查、正式构建及 47 个前端测试通过。

## 左侧远景星云延伸

插画舞台限制最大宽度后，左侧大屏留白只剩渐变底色，形成明显的空带。给全屏底景增加柔化的远景星云，复用原画右下角星云区域，并以水平和垂直遮罩渐隐衔接；裁取范围避开纸片与金色星轨，避免重复道具。人物、表单尺寸及两者间距保持原值，现有闪烁、显形和隧道动画继续保留。

生产构建通过。浏览器检查 1920×958、2560×1440 和 390×844，左侧背景衔接正常，手机文档宽度与视口宽度均为 390px，无横向溢出。

## 星云底色差修正

上次远景补充后仍有明显色差：原画自身的深黑底覆盖了更亮的全屏渐变，显出插画矩形边界。降低底景蓝色亮度和远景透明度，将整个插画舞台以 screen 模式与全屏背景合成，让暗部融合，保留亮星、人物与星轨；同时扩展原画左侧的羽化区。混合放在舞台层以跨越其 transform 产生的堆叠上下文，而非只放在内部星云层。

正式构建通过。浏览器对比 1920×958 和 2560×1440 的背景过渡，并复核手机宽度与持续动效。
